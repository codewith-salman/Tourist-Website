## 📖 About The Project

<img src="Tourist%20Website/assets/images/screenshot.PNG" alt="YourTour Website Screenshot" width="100%" />

**YourTour** is a clean, modern, and UI-focused tourist website designed to promote travel destinations and experiences.

The project emphasizes:
- Strong visual storytelling  
- Clear call-to-actions for travel exploration  
- Modern and responsive layout design  
- User-friendly section flow  

This project is ideal for:
- Travel agencies  
- Tourism startups  
- UI/UX portfolio projects  
- Front-end design demos  

This is a **front-end only project**, built for learning, UI practice, and portfolio showcasing — no backend integration included.

---

## ✨ Features

- Modern tourist website landing page  
- Engaging hero section with travel CTA  
- Destination highlights and offers  
- Fully responsive layout (desktop, tablet, mobile)  
- Smooth hover effects and UI interactions  
- Clean and professional visual design
